## Cómo utilizar esta carpeta

1. Para entender el evento, leer overview, rules y submission; las reglas vigentes de la sede prevalecen sobre el resumen del kit.
2. Para implementar, leer el AGENTS y el README del checkout real. Los documentos aquí son evidencia de la revisión, no sustituyen instrucciones nuevas del upstream.
3. Para nuestras decisiones, leer [PRD](../../PRD.md), [TASKS](../../TASKS.md) y [revisión técnica](../../STARTER-REVIEW.md).
4. No ejecutar scripts de onboarding sólo por leer esta documentación. El PRD elige adaptar Web y un aviso saliente, sin aprovisionar las tres plantillas.
